# Tickets 7.0.0 Recovered Source

This directory contains source code recovered from the official Tickets v7.0.0 release APK.

The recovered code is not guaranteed to be byte-for-byte identical to the original authoring source. It is provided for reference, study, learning, maintenance, and continued open-source development.

The Android package namespace is preserved as `com.example.tickets`.

The recovery was performed from the released APK rather than from the author's current development project.
